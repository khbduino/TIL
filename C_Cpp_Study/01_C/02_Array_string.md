# Array & String

> **학습 목표**
>
> C에서 배열(Array)과 문자열(String)의 기본 구조를 이해하고, **같은
> 타입의 연속 데이터 → 인덱스 → 반복문 → 배열 크기 → 문자열과 `'\0'` →
> 함수 전달 → 주소 → 포인터 → 버퍼 → 임베디드 통신 데이터**로 이어지는
> 관계를 이해한다.
>
> 이 노트는 `C_Cpp_Study/01_C/Array_String.md`에 위치하며
> `00_Common/Function.md` 다음 단계로 학습한다.
>
> 배열과 문자열은 이후 `Pointer.md`, `Memory_Model.md`, `Struct.md`,
> UART Buffer, Ring Buffer를 이해하기 위한 핵심 기반이다.

------------------------------------------------------------------------

# 1. 배열이란?

### 한 문장 정의

**배열(Array)은 같은 자료형의 여러 데이터를 연속된 형태로 묶어서
관리하는 자료구조다.**

변수를 각각 선언하면:

``` c
int score1 = 90;
int score2 = 80;
int score3 = 70;
int score4 = 100;
```

배열을 사용하면:

``` c
int scores[4] = {90, 80, 70, 100};
```

``` mermaid
flowchart LR
    A["scores[0]<br/>90"] --> B["scores[1]<br/>80"]
    B --> C["scores[2]<br/>70"]
    C --> D["scores[3]<br/>100"]
```

> **핵심 관점:** 배열은 여러 변수를 단순히 묶은 것이 아니라, **같은
> 타입의 요소가 연속적으로 배치되는 구조**다.

------------------------------------------------------------------------

# 2. 배열이 필요한 이유

학생 100명의 점수를 저장한다고 가정한다.

배열 없이 작성하면:

``` text
score1
score2
score3
...
score100
```

배열을 사용하면:

``` c
int scores[100];
```

그리고 반복문으로 처리할 수 있다.

``` c
for (int i = 0; i < 100; i++)
{
    /* scores[i] 처리 */
}
```

``` mermaid
flowchart LR
    A["Array"] --> B["Index"]
    B --> C["Loop"]
    C --> D["여러 데이터 일괄 처리"]
```

배열은 `Control_Flow.md`에서 학습한 반복문과 매우 밀접하게 연결된다.

------------------------------------------------------------------------

# 3. 배열 선언

기본 형식:

``` c
자료형 배열이름[요소개수];
```

예:

``` c
int numbers[5];
```

의미:

``` text
int      → 각 요소의 자료형
numbers  → 배열 이름
5        → 요소 개수
```

개념적으로:

``` text
numbers

Index     Element
─────     ───────
  0         ?
  1         ?
  2         ?
  3         ?
  4         ?
```

> \[!WARNING\] 지역 배열을 초기화하지 않은 상태에서 요소의 값을 읽으면
> 안 된다.

------------------------------------------------------------------------

# 4. 배열 초기화

배열을 선언하면서 값을 지정할 수 있다.

``` c
int numbers[5] = {10, 20, 30, 40, 50};
```

``` text
Index       0    1    2    3    4
          ┌────┬────┬────┬────┬────┐
Value     │ 10 │ 20 │ 30 │ 40 │ 50 │
          └────┴────┴────┴────┴────┘
```

------------------------------------------------------------------------

## 4.1 크기 생략

초기값이 있으면 배열 크기를 생략할 수 있다.

``` c
int numbers[] = {10, 20, 30, 40, 50};
```

컴파일러가 초기값의 개수를 이용해 배열 크기를 결정한다.

------------------------------------------------------------------------

## 4.2 일부만 초기화

``` c
int numbers[5] = {10, 20};
```

나머지 요소는 해당 초기화 규칙에 따라 0으로 초기화된다.

개념적으로:

``` text
10 20 0 0 0
```

전체를 0으로 초기화할 때 다음 표현을 자주 사용한다.

``` c
int numbers[5] = {0};
```

> \[!NOTE\] `int numbers[5];`와 `int numbers[5] = {0};`는 같다고
> 생각하면 안 된다.

------------------------------------------------------------------------

# 5. 인덱스

배열의 각 요소는 **인덱스(Index)**로 접근한다.

``` c
int numbers[5] = {10, 20, 30, 40, 50};

printf("%d\n", numbers[0]);
printf("%d\n", numbers[1]);
```

배열 인덱스는 `0`부터 시작한다.

``` text
Element Count = 5

Valid Index:
0
1
2
3
4
```

``` mermaid
flowchart LR
    A["배열 크기 N"] --> B["첫 인덱스 = 0"]
    B --> C["마지막 인덱스 = N - 1"]
```

> \[!IMPORTANT\] 크기가 `N`인 배열의 유효 인덱스 범위는 `0 ~ N-1`이다.

------------------------------------------------------------------------

# 6. 배열 요소 변경

배열의 특정 요소는 일반 변수처럼 사용할 수 있다.

``` c
int numbers[3] = {10, 20, 30};

numbers[1] = 100;
```

결과:

``` text
Before
10 20 30

After
10 100 30
```

연산도 가능하다.

``` c
numbers[0] += 5;
numbers[2]++;
```

즉:

``` c
numbers[index]
```

는 특정 배열 요소를 나타내는 표현이다.

# 7. 배열과 반복문

배열은 반복문과 함께 사용할 때 특히 유용하다.

``` c
int numbers[5] = {10, 20, 30, 40, 50};

for (int i = 0; i < 5; i++)
{
    printf("%d\n", numbers[i]);
}
```

``` mermaid
flowchart TD
    A["i = 0"] --> B{"i < 5?"}
    B -->|"Yes"| C["numbers[i] 접근"]
    C --> D["i++"]
    D --> B
    B -->|"No"| E["종료"]
```

배열 처리의 기본 패턴:

``` c
for (int i = 0; i < size; i++)
{
    /* array[i] 처리 */
}
```

이 패턴은 앞으로 매우 자주 사용한다.

# 8. 배열의 합

``` c
int numbers[5] = {10, 20, 30, 40, 50};
int sum = 0;

for (int i = 0; i < 5; i++)
```

``` text
개수 세기
조건에 맞는 값 찾기
```

# 9. 배열의 최댓값

``` c
int numbers[5] = {30, 10, 80, 20, 50};

int max_value = numbers[0];

for (int i = 1; i < 5; i++)
{
    if (numbers[i] > max_value)
    {
        max_value = numbers[i];
    }
}
```

``` mermaid
flowchart TD
    A["max = 첫 요소"] --> B["다음 요소 확인"]
    B --> C{"현재 요소 > max?"}
    C -->|"Yes"| D["max 갱신"]
    C -->|"No"| E["유지"]
    D --> F["다음 요소"]
    E --> F
    F --> B
```

여기에는 지금까지 학습한 내용이 모두 들어 있다.

``` text

+

+

+

```

# 10. `sizeof`와 배열

배열 전체 크기는 `sizeof`로 확인할 수 있다.

``` c
int numbers[5];

printf("%zu\n", sizeof(numbers));
```

배열 요소 하나의 크기:

``` c
sizeof(numbers[0])
```

배열 요소 개수를 계산하는 대표적인 표현:

``` c
sizeof(numbers) / sizeof(numbers[0])
```

예:

``` c
int numbers[] = {10, 20, 30, 40, 50};

size_t count = sizeof(numbers) / sizeof(numbers[0]);
```

``` mermaid
flowchart TD
    A["sizeof(numbers)"] --> C["배열 전체 크기"]
    B["sizeof(numbers[0])"] --> D["요소 하나의 크기"]
    C --> E["전체 / 요소 하나"]
    D --> E
    E --> F["요소 개수"]
```

> \[!IMPORTANT\] 이 계산 방식은 실제 배열 객체가 존재하는 스코프에서
> 사용할 때 의미가 있다. 배열을 함수 매개변수로 전달한 뒤에도 같은
> 방식으로 원래 요소 수를 구할 수 있다고 생각하면 안 된다. 이 차이는
> `Pointer.md`에서 자세히 다룬다.

# 11. 배열의 메모리 구조

배열의 핵심 특징은 같은 타입의 요소들이 연속적으로 배치된다는 것이다.

예:

``` c
int numbers[4] = {10, 20, 30, 40};
```

개념적인 모습:

``` text
Memory

낮은 주소
   ↓
┌─────────────┐
│ numbers[0]  │
├─────────────┤
│ numbers[1]  │
├─────────────┤
│ numbers[2]  │
├─────────────┤
│ numbers[3]  │
└─────────────┘
   ↓
높은 주소
```

``` mermaid
flowchart LR
    A["Array"] --> B["같은 타입"]
    B --> C["연속된 요소"]
    C --> D["Index"]
    D --> E["Address"]
    E --> F["Pointer"]
```

이 구조가 배열과 포인터가 밀접하게 연결되는 이유다.

# 12. 배열 범위 초과

다음 배열이 있다.

``` c
int numbers[5];
```

유효한 인덱스:

``` text
0
1
2
3
4
```

다음 접근은 범위를 벗어난다.

``` c
numbers[5] = 100;
```

``` text
Valid:
numbers[0] ~ numbers[4]

Invalid:
numbers[5]
```

> \[!WARNING\] C에서는 배열 범위를 자동으로 검사해주는 안전장치가
> 일반적으로 없다. 범위를 벗어난 접근은 **Undefined Behavior**를
> 일으킨다.

이는 임베디드에서도 매우 위험한 버그가 될 수 있다.

``` mermaid
flowchart LR
    A["잘못된 Index"] --> B["Out-of-Bounds"]
    B --> C["다른 메모리 침범 가능"]
    C --> D["예측 불가능한 동작"]
```

# 13. Off-by-One Error와 배열

다음 반복문은 정상적인 패턴이다.

``` c
for (int i = 0; i < 5; i++)
{
    printf("%d\n", numbers[i]);
}
```

하지만:

``` c
for (int i = 0; i <= 5; i++)
{
    printf("%d\n", numbers[i]);
}
```

마지막 반복에서:

``` c
numbers[5]
```

에 접근하게 된다.

``` mermaid
flowchart TD
    A["Array Size = 5"] --> B["Valid Index = 0~4"]
    B --> C["i < 5"]
    C --> D["정상"]
    B --> E["i <= 5"]
    E --> F["i = 5 발생"]
    F --> G["Out-of-Bounds"]
```

> **배열과 반복문을 함께 사용할 때 `i < size` 패턴을 먼저 확인한다.**

# 14. 2차원 배열

배열의 요소가 다시 배열인 구조를 만들 수 있다.

``` c
int matrix[2][3] =
{
    {1, 2, 3},
    {4, 5, 6}
};
```

개념적으로:

            Column 0   Column 1   Column 2
  ------- ---------- ---------- ----------
  Row 0            1          2          3
  Row 1            4          5          6

접근:

``` c
matrix[0][0]
matrix[0][1]
matrix[1][2]
```

------------------------------------------------------------------------

## 14.1 2차원 배열과 중첩 반복문

``` c
for (int row = 0; row < 2; row++)
{
    for (int col = 0; col < 3; col++)
    {
        printf("%d ", matrix[row][col]);
    }

    printf("\n");
}
```

``` mermaid
flowchart TD
    A["row 반복"] --> B["col 반복"]
    B --> C["matrix[row][col]"]
    C --> B
    B -->|"한 행 완료"| A
```

2차원 배열은 이후 다음 분야에서 활용될 수 있다.

``` text
행렬
격자 문제
게임 맵
이미지 데이터
프레임 버퍼
```

# 15. 문자열이란?

C에는 C++의 `std::string`과 같은 방식의 문자열 타입을 기본 문법으로
사용하는 것이 아니라, 기본적으로 **문자 배열을 이용해 문자열을
표현**한다.

``` c
char name[] = "ABC";
```

개념적인 메모리:

``` text
Index      0     1     2     3
         ┌─────┬─────┬─────┬─────┐
Value    │ 'A' │ 'B' │ 'C' │'\0' │
         └─────┴─────┴─────┴─────┘
```

> **C 문자열의 핵심은 마지막의 널 문자 `'\0'`이다.**

------------------------------------------------------------------------

# 16. 문자와 문자열

`Data_Type.md`에서 배운 내용을 다시 연결한다.

``` c
'A'
```

는 문자다.

``` c
"A"
```

는 문자열 리터럴이다.

  표현    의미
  ------- ---------------------------------
  `'A'`   문자 하나
  `"A"`   `'A'`, `'\0'`로 표현되는 문자열

개념:

``` text
'A'

┌─────┐
│ 'A' │
└─────┘
```

``` text
"A"

┌─────┬─────┐
│ 'A' │'\0' │
└─────┴─────┘
```

> \[!IMPORTANT\] 문자열에는 끝을 나타내는 `'\0'` 공간이 필요하다.

------------------------------------------------------------------------

# 17. 널 문자 `'\0'`

C 문자열은 `'\0'`을 만나면 문자열이 끝났다고 판단하는 방식으로 사용된다.

``` c
char text[] = "Hello";
```

개념:

``` text
'H' 'e' 'l' 'l' 'o' '\0'
```

문자 수는 5개지만 배열 요소는 6개다.

``` mermaid
flowchart LR
    A["H"] --> B["e"]
    B --> C["l"]
    C --> D["l"]
    D --> E["o"]
    E --> F["\\0"]
    F --> G["문자열 끝"]
```

------------------------------------------------------------------------

# 18. 문자열과 `sizeof`

``` c
char text[] = "ABC";
```

배열에는 다음 요소가 들어 있다.

``` text
'A'
'B'
'C'
'\0'
```

따라서 일반적인 8-bit byte 환경뿐 아니라 C 표준의 정의상
`sizeof(char) == 1`이므로:

``` c
sizeof(text)
```

는 `4`다.

> \[!NOTE\] `sizeof(char)`는 C/C++에서 항상 1이다. 다만 표준에서 말하는
> 1 byte가 반드시 8 bit라고 일반화할 수는 없다. 임베디드에서 정확한 비트
> 폭이 중요해지면 `CHAR_BIT`와 fixed-width integer를 함께 학습한다.

# 19. 문자열 출력

`printf()`에서 문자열은 `%s`를 사용한다.

``` c
#include <stdio.h>

int main(void)
{
    char name[] = "Alice";

    printf("%s\n", name);

    return 0;
}
```

문자 하나는 `%c`를 사용한다.

``` c
char grade = 'A';

printf("%c\n", grade);
```

  데이터   형식 지정자
  -------- -------------
  문자     `%c`
  문자열   `%s`

------------------------------------------------------------------------

# 20. 문자열 입력

간단한 문자열 입력 예:

``` c
char name[20];

scanf("%19s", name);
```

여기서 배열 크기가 20이므로 `'\0'`을 위한 공간을 남기기 위해 최대
19문자까지만 읽도록 제한한다.

> \[!WARNING\] 문자열 입력에서는 버퍼 크기를 반드시 의식해야 한다. 제한
> 없이 데이터를 기록하면 배열 범위를 넘어설 수 있다.

또한 `%s` 입력은 공백에서 끊기는 특성이 있다.

``` text
입력:
Hello World

%s 하나로 읽으면 첫 단어까지만 읽는 형태가 될 수 있음
```

문장 입력과 안전한 입력 함수의 세부 내용은 이후 문자열/입력 처리
실습에서 확장한다.

------------------------------------------------------------------------

# 21. 문자열 직접 순회

문자열도 배열이므로 인덱스로 접근할 수 있다.

``` c
char text[] = "ABC";

printf("%c\n", text[0]);
printf("%c\n", text[1]);
printf("%c\n", text[2]);
```

반복문으로 순회할 수 있다.

``` c
for (int i = 0; text[i] != '\0'; i++)
{
    printf("%c\n", text[i]);
}
```

``` mermaid
flowchart TD
    A["i = 0"] --> B{"text[i] != '\\0'?"}
    B -->|"Yes"| C["text[i] 처리"]
    C --> D["i++"]
    D --> B
    B -->|"No"| E["문자열 끝"]
```

이 패턴은 C 문자열 처리의 핵심이다.

------------------------------------------------------------------------

# 22. 문자열 길이 직접 계산

``` c
int string_length(const char text[])
{
    int length = 0;

    while (text[length] != '\0')
    {
        length++;
    }

    return length;
}
```

예:

``` c
char text[] = "Hello";

int length = string_length(text);
```

결과:

``` text
5
```

``` mermaid
flowchart LR
    A["문자 확인"] --> B{"\\0 인가?"}
    B -->|"No"| C["length++"]
    C --> A
    B -->|"Yes"| D["길이 반환"]
```

> \[!NOTE\] 위 함수의 배열 매개변수와 `const`의 정확한 의미는 포인터 및
> `const` 학습에서 더 자세히 다룬다. 현재는 문자열을 변경하지 않고 읽는
> 함수라는 의도로 이해한다.

# 23. `<string.h>`

C 표준 라이브러리는 문자열 처리를 위한 여러 함수를 제공한다.

``` c
#include <string.h>
```

대표적인 함수:

  함수         기본 목적
  ------------ --------------------
  `strlen()`   문자열 길이
  `strcmp()`   문자열 비교
  `strcpy()`   문자열 복사
  `strcat()`   문자열 이어 붙이기

예:

``` c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char text[] = "Hello";

    printf("%zu\n", strlen(text));

    return 0;
}
```

> \[!WARNING\] 복사와 이어 붙이기 함수는 목적지 버퍼 크기를 반드시
> 고려해야 한다. 함수 이름만 외우고 무조건 사용하는 방식은 피한다.

현재 단계에서는 `strlen()` 정도를 사용해보고, 직접 문자열을 순회하는
원리도 함께 이해한다.

# 24. `sizeof`와 `strlen`

두 개념을 구분해야 한다.

``` c
char text[] = "ABC";
```

``` c
sizeof(text)
```

는 배열 자체가 차지하는 크기를 본다.

``` c
strlen(text)
```

는 `'\0'` 이전까지의 문자열 길이를 계산한다.

이 예에서는:

``` text
sizeof(text) → 4
strlen(text) → 3
```

``` mermaid
flowchart TD

    A --> C["strlen(text)"]
    B --> D["배열 크기: 4"]
    C --> E["문자열 길이: 3"]
```

> \[!IMPORTANT\] `sizeof`와 `strlen`은 같은 개념이 아니다.

# 25. 문자열 비교

문자열 내용을 비교할 때 다음처럼 작성한다고 생각하기 쉽다.

``` c
text1 == text2
```

하지만 C 문자열의 내용을 비교하는 일반적인 방식은 `strcmp()`를 사용하는
것이다.

``` c
strcmp(text1, text2)
```

두 문자열이 같다면:

``` c
strcmp(text1, text2) == 0
```

예:

``` c
#include <string.h>

char a[] = "ABC";
char b[] = "ABC";

if (strcmp(a, b) == 0)
{
    /* 문자열 내용이 같음 */
}
```

> \[!WARNING\] C 문자열의 **내용 비교**를 단순히 `==`로 처리하지 않는다.
> 배열과 포인터를 배우면 그 이유를 더 정확히 이해할 수 있다.

# 28. 함수 안에서 `sizeof(array)` 주의

다음 코드를 보고 배열 크기를 구할 수 있다고 생각하면 안 된다.

``` c
void print_array(int numbers[])
{
    size_t count = sizeof(numbers) / sizeof(numbers[0]);
}
```

함수 매개변수의 `numbers[]`는 실제 배열 객체 자체가 전달되는 형태가
아니다.

따라서 보통 크기를 별도로 전달한다.

``` c
void print_array(int numbers[], int size)
{
    for (int i = 0; i < size; i++)
    {
        printf("%d\n", numbers[i]);
    }
}
```

``` mermaid
flowchart LR
    A["Array"] --> B["Function"]
    A --> C["Size"]
    C --> B
    B --> D["안전한 범위 반복"]
```

이 지점부터 포인터를 배울 필요성이 명확해진다.

# 49. Bug Log에 기록할 항목

배열 관련 실수는 `99_Bug_Log`에 다음처럼 기록한다.

```` markdown
## 배열 범위 초과

### 잘못 작성한 코드

```c
int numbers[5];

for (int i = 0; i <= 5; i++)
{
    numbers[i] = 0;
}
```

### 증상

배열의 범위를 벗어난 메모리에 접근할 수 있다.

### 원인

크기가 5인 배열의 유효한 인덱스는 `0 ~ 4`인데 반복 조건을 `i <= 5`로 작성했다.

### 수정

```c
for (int i = 0; i < 5; i++)
{
    numbers[i] = 0;
}
```

### 재발 방지 규칙

배열 반복문을 작성할 때 항상 다음을 확인한다.

1. 배열 요소 개수
2. 시작 인덱스
3. 마지막 유효 인덱스
4. 반복문의 종료 조건
````

``` text
'\0' 공간 누락
```

## 최종적으로 기억할 여섯 문장

> **1. 배열은 같은 타입의 여러 요소를 연속적으로 관리하는 구조다.**

> **2. 크기가 `N`인 배열의 유효한 인덱스는 `0 ~ N-1`이다.**

> **3. 배열과 반복문을 함께 사용할 때는 항상 범위 초과와 Off-by-One
> Error를 확인한다.**

> **4. C 문자열은 `'\0'`으로 끝나는 문자 배열로 이해한다.**

> **5. 배열을 함수에 전달하는 순간 포인터 개념과 직접 연결되기
> 시작한다.**

> **6. 임베디드에서는 배열이
> `메모리 → 버퍼 → 통신 데이터 → Ring Buffer → Packet Parser`로
> 발전한다.**
