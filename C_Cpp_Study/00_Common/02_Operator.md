# Operator

> **학습 목표**
>
> C와 C++에서 공통적으로 사용하는 연산자(Operator)의 종류와 동작을
> 이해하고, 단순히 기호를 암기하는 것이 아니라 **피연산자 → 연산 →
> 결과값 → 결과 타입 → 조건식 → 비트 연산 → 임베디드 레지스터 제어**로
> 이어지는 관계를 이해한다.
>
> 이 노트는 `C_Cpp_Study/00_Common/Operator.md`에 위치하며,
> `Data_Type.md` 다음 단계로 학습한다. 이후 `Control_Flow`,
> `Bit_Operation`, `Pointer`, `Embedded_C` 학습의 기반으로 사용한다.

------------------------------------------------------------------------

## 1. 연산자란?

### 한 문장 정의

**연산자(Operator)는 하나 이상의 값에 특정 연산을 수행하도록 지시하는
기호 또는 표현이다.**

``` c
int result = 10 + 20;
```

위 코드에서:

  요소         의미
  ------------ ----------------------
  `10`, `20`   피연산자(Operand)
  `+`          연산자(Operator)
  `30`         연산 결과
  `result`     결과를 저장하는 변수

``` mermaid
flowchart LR
    A["10"] --> C["+ 연산"]
    B["20"] --> C
    C --> D["30"]
    D --> E["result에 저장"]
```

즉 연산자를 공부할 때는 기호만 외우지 말고 다음 흐름을 같이 본다.

``` text
피연산자
   ↓
연산자
   ↓
연산
   ↓
결과값
   ↓
결과 타입
```

> **핵심 관점:** 연산을 볼 때는 `값 + 타입 + 연산자`를 함께 확인한다.

------------------------------------------------------------------------

# 3. 산술 연산자

산술 연산자는 숫자를 계산할 때 사용한다.

  연산자   의미     예
  -------- -------- ---------
  `+`      덧셈     `a + b`
  `-`      뺄셈     `a - b`
  `*`      곱셈     `a * b`
  `/`      나눗셈   `a / b`
  `%`      나머지   `a % b`

예:

``` c
int a = 10;
int b = 3;

int sum = a + b;
int sub = a - b;
int mul = a * b;
int div = a / b;
int mod = a % b;
```

결과:

  표현         결과
  ---------- ------
  `10 + 3`     `13`
  `10 - 3`      `7`
  `10 * 3`     `30`
  `10 / 3`      `3`
  `10 % 3`      `1`

------------------------------------------------------------------------

## 3.1 정수 나눗셈

`Data_Type.md`에서 배운 것처럼 연산 결과는 피연산자의 타입과 관계가
있다.

``` c
int a = 10;
int b = 3;

int result = a / b;
```

결과:

``` text
3
```

`10 / 3`의 수학적인 결과는 약 `3.333...`이지만 `int / int`이므로 정수
나눗셈이 수행된다.

``` mermaid
flowchart TD
    A["10 / 3"] --> B{"피연산자 타입"}
    B -->|"int / int"| C["정수 나눗셈"]
    C --> D["3"]
```

실수 나눗셈이 필요하다면 피연산자 중 하나를 실수형으로 만든다.

``` c
double result = (double)a / b;
```

------------------------------------------------------------------------

## 3.2 나머지 연산자 `%`

`%`는 정수 나눗셈의 나머지를 구할 때 사용한다.

``` c
int result = 10 % 3;
```

결과:

``` text
1
```

나머지 연산자는 알고리즘 문제에서 매우 자주 사용된다.

대표적인 사용 예:

``` text
짝수 / 홀수 판별
주기적인 값 계산
배수 판별
원형 인덱스
```

짝수 판별:

``` c
int number = 10;

if (number % 2 == 0)
{
    /* 짝수 */
}
```

현재는 `if`의 자세한 동작보다 다음 표현을 먼저 이해한다.

``` c
number % 2 == 0
```

``` mermaid
flowchart LR
    A["number"] --> B["% 2"]
    B --> C["나머지"]
    C --> D{"0인가?"}
    D -->|"Yes"| E["짝수"]
    D -->|"No"| F["홀수"]
```

------------------------------------------------------------------------

# 4. 대입 연산자

가장 기본적인 대입 연산자는 `=`이다.

``` c
int number = 10;

number = 20;
```

두 번째 `=`는 오른쪽 값을 왼쪽 변수에 대입한다.

``` mermaid
flowchart LR
    A["20"] --> B["="]
    B --> C["number"]
```

> \[!IMPORTANT\] `=`는 "같다"가 아니라 **대입**이다.

같은지 비교하는 연산자는 `==`이다.

``` text
=   → 대입
==  → 비교
```

------------------------------------------------------------------------

## 4.1 복합 대입 연산자

다음 코드를 보자.

``` c
int a = 10;

a = a + 5;
```

이 코드는 다음처럼 줄여 쓸 수 있다.

``` c
a += 5;
```

대표적인 복합 대입 연산자:

  연산자     의미
  ---------- -------------
  `a += b`   `a = a + b`
  `a -= b`   `a = a - b`
  `a *= b`   `a = a * b`
  `a /= b`   `a = a / b`
  `a %= b`   `a = a % b`

예:

``` c
int value = 10;

value += 5;   // 15
value -= 3;   // 12
value *= 2;   // 24
value /= 4;   // 6
value %= 4;   // 2
```

변화 과정을 추적하면:

``` mermaid
flowchart LR
    A["10"] --> B["+= 5"]
    B --> C["15"]
    C --> D["-= 3"]
    D --> E["12"]
    E --> F["*= 2"]
    F --> G["24"]
```

------------------------------------------------------------------------

# 5. 비교 연산자

비교 연산자는 두 값을 비교한다.

  연산자   의미
  -------- -------------
  `==`     같다
  `!=`     다르다
  `<`      작다
  `>`      크다
  `<=`     작거나 같다
  `>=`     크거나 같다

예:

``` c
int a = 10;
int b = 20;

a == b;
a != b;
a < b;
a > b;
a <= b;
a >= b;
```

C와 C++ 모두 비교 표현식의 결과를 조건 판단에 사용할 수 있다. C++에서는
비교 결과를 `bool` 값으로 자연스럽게 다룬다.

``` cpp
bool result = (10 < 20);
```

------------------------------------------------------------------------

## 5.1 `=`와 `==`를 반드시 구분한다

초기에 가장 많이 발생하는 실수 중 하나다.

``` c
a = 10;
```

대입이다.

``` c
a == 10
```

비교다.

``` mermaid
flowchart TD
    A["="] --> B["대입"]
    C["=="] --> D["비교"]
    B --> E["변수의 값을 변경"]
    D --> F["두 값의 관계를 판단"]
```

> \[!WARNING\] 조건문을 작성할 때 `==` 대신 `=`를 작성하는 실수는 반드시
> Bug Log에 기록한다.

------------------------------------------------------------------------

# 6. 논리 연산자

여러 조건을 조합할 때 논리 연산자를 사용한다.

  연산자   이름   의미
  -------- ------ -------------------
  `&&`     AND    두 조건이 모두 참
  `||`     OR     하나 이상 참
  `!`      NOT    참/거짓 반전

------------------------------------------------------------------------

## 6.1 AND `&&`

예를 들어 나이가 20 이상이고 30 이하인지 검사한다고 하자.

``` c
age >= 20 && age <= 30
```

``` mermaid
flowchart LR
    A["age >= 20"] --> C["&&"]
    B["age <= 30"] --> C
    C --> D["둘 다 참이면 참"]
```

예:

``` c
int age = 25;

if (age >= 20 && age <= 30)
{
    /* 20대 범위 */
}
```

------------------------------------------------------------------------

## 6.2 OR `||`

두 조건 중 하나 이상이 참인지 검사한다.

``` c
score < 0 || score > 100
```

``` mermaid
flowchart LR
    A["score < 0"] --> C["||"]
    B["score > 100"] --> C
    C --> D["하나 이상 참이면 참"]
```

이 표현은 점수가 정상 범위를 벗어났는지 검사할 때 사용할 수 있다.

------------------------------------------------------------------------

## 6.3 NOT `!`

조건을 반대로 만든다.

``` c
!condition
```

C++ 예:

``` cpp
bool running = false;

if (!running)
{
    // running이 false일 때 실행
}
```

개념적으로:

``` text
true  → ! → false
false → ! → true
```

------------------------------------------------------------------------

# 7. Short-Circuit Evaluation

`&&`와 `||`는 **단락 평가(short-circuit evaluation)**를 수행한다.

이 개념은 이후 포인터와 임베디드 코드에서도 중요하다.

## 7.1 `&&`

``` c
A && B
```

`A`가 거짓이면 전체 결과는 이미 거짓이다.

따라서 `B`를 평가할 필요가 없다.

``` mermaid
flowchart TD
    A["A 평가"] --> B{"A가 참인가?"}
    B -->|"No"| C["전체 결과: 거짓"]
    B -->|"Yes"| D["B 평가"]
    D --> E["전체 결과 결정"]
```

------------------------------------------------------------------------

## 7.2 `||`

``` c
A || B
```

`A`가 참이면 전체 결과는 이미 참이다.

``` mermaid
flowchart TD
    A["A 평가"] --> B{"A가 참인가?"}
    B -->|"Yes"| C["전체 결과: 참"]
    B -->|"No"| D["B 평가"]
    D --> E["전체 결과 결정"]
```

------------------------------------------------------------------------

## 7.3 포인터와 연결되는 예

이후 포인터를 배우면 다음과 같은 코드를 접할 수 있다.

``` c
if (ptr != NULL && *ptr == 10)
{
    /* ... */
}
```

`ptr == NULL`이면 첫 번째 조건이 거짓이므로 `*ptr == 10`은 평가하지
않는다.

``` mermaid
flowchart LR
    A["ptr != NULL"] --> B{"참?"}
    B -->|"No"| C["*ptr 평가하지 않음"]
    B -->|"Yes"| D["*ptr == 10 평가"]
```

> \[!IMPORTANT\] 현재 포인터 문법을 외울 필요는 없다. 논리 연산자의 단락
> 평가가 이후 **안전한 조건 검사**와 연결된다는 점만 기억한다.

------------------------------------------------------------------------

# 8. 증감 연산자

변수의 값을 1 증가하거나 감소시킬 때 사용한다.

``` c
a++;
a--;

++a;
--a;
```

  연산자   의미
  -------- --------
  `++`     1 증가
  `--`     1 감소

예:

``` c
int count = 10;

count++;
```

최종 결과:

``` text
count = 11
```

------------------------------------------------------------------------

## 8.1 전위와 후위

다음 두 표현이 있다.

``` c
++a;
a++;
```

변수 하나만 단독 문장으로 사용하면 둘 다 `a`를 1 증가시킨다.

하지만 다른 표현식 안에서 사용하면 차이가 발생한다.

### 후위 증가

``` c
int a = 10;
int b = a++;
```

개념적으로:

``` text
b에 기존 a 값 10 사용
        ↓
a를 11로 증가
```

최종:

``` text
a = 11
b = 10
```

### 전위 증가

``` c
int a = 10;
int b = ++a;
```

개념적으로:

``` text
a를 11로 증가
        ↓
증가된 값 11 사용
        ↓
b = 11
```

최종:

``` text
a = 11
b = 11
```

``` mermaid
flowchart TD
    A["a = 10"] --> B{"표현"}
    B -->|"b = a++"| C["b = 10"]
    C --> D["a = 11"]
    B -->|"b = ++a"| E["a = 11"]
    E --> F["b = 11"]
```

> \[!TIP\] 처음에는 `++`와 `--`를 복잡한 표현식 안에 넣기보다 독립된
> 문장으로 사용하는 편이 코드를 이해하기 쉽다.

------------------------------------------------------------------------

# 9. 연산자 우선순위

다음 표현을 보자.

``` c
int result = 2 + 3 * 4;
```

곱셈이 덧셈보다 먼저 수행된다.

``` text
3 * 4 = 12
2 + 12 = 14
```

결과:

``` text
14
```

괄호를 사용하면 순서를 명확하게 바꿀 수 있다.

``` c
int result = (2 + 3) * 4;
```

결과:

``` text
20
```

------------------------------------------------------------------------

## 9.1 괄호를 적극적으로 사용한다

모든 연산자 우선순위 표를 처음부터 외우는 것은 권장하지 않는다.

다음처럼 코드의 의도를 명확하게 표현한다.

``` c
int result = (a + b) * c;
```

조건식도 마찬가지다.

``` c
if ((age >= 20) && (age <= 30))
{
    /* ... */
}
```

단순한 경우 괄호가 반드시 필요한 것은 아니지만 학습 초기에는 그룹을
명확하게 보여주는 데 도움이 된다.

> \[!TIP\] **우선순위가 헷갈리면 괄호를 사용한다.**

------------------------------------------------------------------------

# 10. 비트 연산자

비트 연산자는 데이터를 **bit 단위**로 연산한다.

임베디드 프로그래밍에서 특히 중요하다.

  연산자   의미
  -------- -------------
  `&`      Bitwise AND
  `|`      Bitwise OR
  `^`      Bitwise XOR
  `~`      Bitwise NOT
  `<<`     Left Shift
  `>>`     Right Shift

> \[!IMPORTANT\] 이 `Operator.md`에서는 비트 연산자의 존재와 기본 원리만
> 이해한다.
>
> 실제 레지스터 제어, 비트 마스크, set/clear/toggle은
> `01_C/Bit_Operation.md`에서 자세히 다룬다.

------------------------------------------------------------------------

## 10.1 Bitwise AND `&`

예:

``` text
  1100
& 1010
------
  1000
```

두 비트가 모두 `1`인 위치만 `1`이 된다.

``` mermaid
flowchart LR
    A["1100"] --> C["Bitwise AND &"]
    B["1010"] --> C
    C --> D["1000"]
```

C 코드:

``` c
unsigned int a = 0x0C;
unsigned int b = 0x0A;

unsigned int result = a & b;
```

------------------------------------------------------------------------

## 10.2 Bitwise OR `|`

``` text
  1100
| 1010
------
  1110
```

둘 중 하나 이상이 `1`이면 `1`이다.

------------------------------------------------------------------------

## 10.3 Bitwise XOR `^`

``` text
  1100
^ 1010
------
  0110
```

두 비트가 서로 다르면 `1`이다.

------------------------------------------------------------------------

## 10.4 Bitwise NOT `~`

각 비트를 반전한다.

개념적으로:

``` text
0 → 1
1 → 0
```

실제 결과는 자료형의 비트 폭에 따라 달라지므로 단순히 표시된 몇 비트만
보고 전체 정수값을 판단하지 않는다.

------------------------------------------------------------------------

## 10.5 Shift `<<`, `>>`

비트를 왼쪽 또는 오른쪽으로 이동한다.

``` c
value << 1;
value >> 1;
```

개념 예:

``` text
0000 0001
    << 1
0000 0010
```

``` mermaid
flowchart LR
    A["0000 0001"] -->|"&lt;&lt; 1"| B["0000 0010"]
```

이후 임베디드에서는 다음과 같은 표현을 자주 사용한다.

``` c
1u << 3
```

개념적으로 특정 비트 위치를 나타내는 마스크를 만드는 데 활용할 수 있다.

``` text
0000 0001
    << 3
0000 1000
```

------------------------------------------------------------------------

# 11. 논리 연산자와 비트 연산자를 구분한다

초기에 매우 중요하다.

``` text
&&   논리 AND
&    비트 AND

||   논리 OR
|    비트 OR
```

  종류        AND    OR
  ----------- ------ ------
  논리 연산   `&&`   `||`
  비트 연산   `&`    `|`

예:

``` c
if (a > 0 && b > 0)
{
    /* 논리 조건 */
}
```

``` c
unsigned int masked = value & mask;
```

> \[!WARNING\] `&&`와 `&`, `||`와 `|`는 서로 다른 연산자다.

이 차이는 임베디드 코드에서 특히 중요하다.

------------------------------------------------------------------------

# 12. 조건 연산자 `?:`

조건에 따라 두 값 중 하나를 선택할 수 있다.

형식:

``` c
condition ? value_if_true : value_if_false
```

예:

``` c
int a = 10;
int b = 20;

int max = (a > b) ? a : b;
```

동작:

``` mermaid
flowchart TD
    A["a > b"] --> B{"조건"}
    B -->|"true"| C["a 선택"]
    B -->|"false"| D["b 선택"]
    C --> E["max"]
    D --> E
```

위 코드는 `a > b`가 참이면 `a`, 거짓이면 `b`를 선택한다.

> 중첩하면 가독성이 떨어질 수 있다.

# 15. 자주 하는 실수

## 15.1 `=`와 `==` 혼동

잘못된 의도:

``` c
if (a = 10)
{
    /* ... */
}
```

`a == 10`을 의도했다면 다음과 같이 작성해야 한다.

``` c
if (a == 10)
{
    /* ... */
}
```

> \[!WARNING\] `=`는 대입이고 `==`는 비교다.

------------------------------------------------------------------------

## 15.2 정수 나눗셈

``` c
int a = 10;
int b = 3;

double result = a / b;
```

`result`의 타입만 보고 실수 나눗셈이라고 생각하지 않는다.

``` c
double result = (double)a / b;
```

------------------------------------------------------------------------

## 15.3 `&&`와 `&` 혼동

``` c
condition1 && condition2
```

는 논리 AND다.

``` c
value & mask
```

는 비트 AND다.

------------------------------------------------------------------------

## 15.4 `||`와 `|` 혼동

``` c
condition1 || condition2
```

는 논리 OR다.

``` c
value | mask
```

는 비트 OR다.

------------------------------------------------------------------------

## 15.5 증감 연산자를 복잡하게 사용

다음과 같이 한 표현식에 여러 변경을 섞으면 읽고 추론하기 어려워진다.

``` c
/* 학습 초기에는 이런 형태를 피한다. */
result = a++ + ++b;
```

가능하면 의미가 분명하게 분리한다.

``` c
a++;
++b;
result = a + b;
```

------------------------------------------------------------------------

## 15.6 우선순위를 잘못 예상

``` c
int result = a + b * c;
```

의도를 명확하게 표현해야 한다면 괄호를 사용한다.

``` c
int result = a + (b * c);
```

또는:

``` c
int result = (a + b) * c;
```



예를 들어 이후 다음과 같은 코드로 발전한다.

``` c

```

현재 단계에서는 이 코드를 완전히 이해할 필요는 없다.

앞으로 다음 순서로 분해해서 학습한다.

``` mermaid
flowchart TD
    A["1u"] --> B["1u << 3"]
    B --> C["Bit Mask"]
    C --> D["register_value | mask"]
    D --> E["특정 Bit 설정"]
```

## 최종적으로 기억할 다섯 문장

> **1. 연산자는 피연산자에 특정 연산을 수행하고 결과를 만든다.**

> **2. 연산 결과를 판단할 때는 값뿐 아니라 피연산자의 자료형을 함께
> 확인한다.**

> **3. `=`는 대입, `==`는 비교이며 서로 완전히 다른 연산자다.**

> **4. `&&`, `||`는 논리 연산이고 `&`, `|`는 비트 연산이다.**

> **5. 임베디드에서는
> `자료형 → 연산자 → 비트 연산 → 비트 마스크 → 레지스터 → 하드웨어`로
> 연결된다.**
