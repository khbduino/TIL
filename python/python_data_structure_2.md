## 딕셔너리

- 키(Key)와 값(Value)을 짝지어 저장하는 자료구조

- 딕셔너리는 내부적으로 해시 테이블을 사용하여 키-값 쌍을 관리
- 키를 통한 값읜 삽입, 복제, 검색이 데이터의 크기와 관계없이 매우 빠름
- 키는 해쉬한 고유값

### 딕셔너리의 메서드

#### .get(key[,default])

- 딕셔너리의 키를 이용하여 값을 반환받기 위해
  
#### .keys()

- 딕셔너리 키를 모은 객체를 반환
- .keys()를 사용하면 dict_keys 객체를 반환함
- 반복 가능한 형태로 반환

#### .values()

- 딕셔너리 값을 모은 객체를 반환
- .values()를 사용하면 dict_values 객체를 반환함
- 반복 가능한 형태로 반환

#### .items()

- 딕셔너리 키/값 쌍을 모은 객체를 반환
- .items()를 사용 시 dict_items를 반환
- 튜플 형태로 반환

#### .setdefault()

- 키와 연결된 값을 반환
- 키가 없다면 default와 연결한 키를 딕셔너리에 **추가**하고 default를 반환
- .setdefault(key[,default])

setdefault 사용시 해당하는 키가 없다면 default의 값과 해당 키를 딕셔너리에 추가하고 반환한다

#### .update()

#### .pop()

- 키를 제거하고 연결됐던 값을 반환 (없으면 에러나 default 반환)
- default를 주어야지만 default를 반환한다
- default 없으면 에러 발생 # KeyError

#### .clear()

- 딕셔너리의 모든 키/값 쌍을 제거

## 딕셔너리의 확장: defaultdict

파이썬 내장 모듈 collections에서 제공하는 딕셔너리의 확장판

- 딕셔너리에 존재하지 않는 키를 조회할 때, 자동으로 기본값을 생성해주는 자료구조
- keyError 걱정 없이 값을 수정하거나 추가할 때 매우 유용함

### 기본 딕션리 vs defaultdict 비교

- 상황: 주어진 문자열에서 각 문자의 등장 횟수 세기

#### defaultdict 구문 및 활용 가이드

- 사용법 `defaultdict(자료형)` 형태로 선언
- 패턴
  1. 숫자 세기: defaultdict(int)
     - 키가 없으면 0으로 초기화
  2. 그룹핑/리스트 모으기: defaultdict(list)
     - 키가 없으면 빈 리스트 []로 초기화

#### defaultdict 주의사항

- defaultdict는 조회만 해도 키가 생성됨
  - 예:`print(my_dict['missing_key'])`를 하면 0이 출력되면서 키가 추가됨
- 따라서 단순히 키가 있는지 확인할 때는 주의해서 사용해야 함

## 세트

### Set

- 고유한 항목들의 정렬되지 않은 컬렉션

> - Set은 내부적으로 해시 테이블을 사용하여 데이터를 저장
> - 이로 인해 항목의 고유성을 효율적으로 보장하며, 항목의 추가, 삭제, 존재 여부 확인(in 연산)이 데이터의 크기에 관계없이 매우 빠릅니다
> - 또한, 합집합(Union), 교집합()

#### 세트 메서드

#### .add(x)

- 세트에 x를 추가

#### .update(iterable)

- 세트에 다른 iterable 요소를 추가

#### Set의 .clear()

- 세트의 모든 항목을 제거

#### .remove(x)

- 세트에서 항목 x를 제거, 항목 x가 없을 경우 keyError

#### 세트의 .pop()

- 세트에서 **임의**의 요소를 제거하고 반환

#### .discard(x)

- 세트 s의 항목 x를 젝 .remove와 달리 에러 없음

### 세트의 집합 메서드

| 메서드 | 설명 | 연산자 |
| :---: | :---: | :---: |
| set1.difference(set2) | set1에는 들어있지만 | set1 - set2 |
| set1.intersection(set2) | set1에는 들어있지만 | set1 & set2 |
| set1.issubset(set2) | set1에는 들어있지만 | set1 <= set2 |
| set1.issuperset(set2) | set1에는 들어있지만 | set1 > set2 |
| set1.union(set2) | set1에는 들어있지만 | set1 \| set2 |

## 참고

### 해시 테이블 (hash table)

- 해시 테이블은 ==키와 값==을 짝지어 저장하는 자료구조

### 해시테이블의 원리

### 해시 (Hash)

- 임의의 크기를 가진 데이터를 고정된 크기의 **고유한 값**으로 변환하는 것

> - 생성된 해시 값(**고유한 정수**)은 해당 데잍를 식별하는 지문 역할을 함
> - 파이썬에서는 이 해시 값을 이용해 해시 테이블에 데이터를 저장
> - 이 변환을 수행하는 것이 해시 함수

### 해시 함수 (Hash function)

- 임의 길이 데이터를 입력 받아 고정 길(정수)로 변환해 주는 함수
- 이 '정수'가 바로 해시 값

> - 주로 해시 테이블을 구현할 때, 매우 빠른 검색 및 데이터 저장 위치 결정을 위해 활용
> - 해시 알고리즘 이라고도 부름

> TIP
> 해시가 빠른 이유
